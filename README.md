# LavitaTech Website

Static marketing website for LavitaTech, designed for GitHub Pages.

## Required root-level image files

Upload these files to the repository root alongside `index.html`:

- `horizontal logo transparent.png`
- `heroLT.png`
- `connava-logo.jpg`
- `legacyloopOFFICIALLOGO.jpg`
- `alignoofficialappicon.png`
- `Poploom-App-Icon-1024x1024.jpg`
- `blindrunnerappcover.png`

GitHub Pages paths and filename capitalization are case-sensitive. Keep the filenames exactly as shown unless you also update `index.html`.

## Publishing

In GitHub:

1. Repository **Settings**
2. **Pages**
3. Under **Build and deployment**, choose **Deploy from a branch**
4. Branch: `main`
5. Folder: `/(root)`
6. Save

## Custom domain

The included `CNAME` file contains:

`lavitatech.com`

Also configure the custom domain in GitHub repository **Settings → Pages** and configure DNS with your DNS provider.
